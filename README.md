# 수행평가 일람표 전자서명기

나이스에서 내려받은 수행평가 일람표 PDF를 올리면, 학생이 태블릿이나 핸드폰에서 자기 점수만 확인하고 서명합니다. 서명은 각 학생의 비고란에 자동으로 들어가고, 다 받으면 원래 일람표 양식 그대로 서명만 들어간 PDF로 내려받을 수 있습니다.

## 사용 주소

https://koreantch-stack.github.io/suhaengsign/

이 저장소 화면에서는 프로그램이 실행되지 않습니다. 위 주소를 크롬이나 사파리에서 열어 주세요.

## 개인정보

- 학생 이름, 점수, 서명은 선생님 기기의 브라우저 안에만 저장되고 어디로도 전송되지 않습니다.
- 이 프로그램이 올라가 있는 GitHub Pages는 화면만 보여 주는 곳이라 데이터를 받을 서버가 없습니다.
- 프로그램 코드는 이 저장소의 index.html에 모두 공개되어 있어 누구나 확인할 수 있습니다.

## 쓰실 때 주의할 점

- 이어서 서명을 받을 때는 처음 쓴 기기와 같은 브라우저로 열어야 합니다. 다른 기기나 다른 브라우저에서는 저장된 일람표가 보이지 않습니다.
- 카카오톡에서 링크를 누르면 카톡 안의 브라우저로 열리는데, 거기서는 저장이 잘 되지 않습니다. 메뉴에서 '다른 브라우저로 열기'를 눌러 크롬이나 사파리로 열어 주세요.
- 아이폰·아이패드의 사파리는 7일 동안 열지 않은 사이트의 저장 데이터를 지울 수 있습니다. 사파리에서 공유 버튼을 누르고 '홈 화면에 추가'로 아이콘을 만들어, 늘 그 아이콘으로 열어 주세요.
- 서명을 다 받은 반은 바로 'PDF 받기'로 내려받아 두세요. 내려받은 PDF는 기기에서 지워지지 않습니다.

## 학교 규정 확인

전자 서명을 학생 확인 서명으로 인정하는지는 학교마다 다를 수 있습니다. 쓰시기 전에 학교 학업성적관리규정을 확인해 주세요.

## 책임 한계

개인이 만든 무료 프로그램입니다. 내려받은 PDF는 결재 전에 서명이 각 학생의 비고란에 맞게 들어갔는지, 점수가 원본과 같은지 한 번 확인하고 써 주세요.
